
# Enterprise Observability Platform UI Prompt (React)

Build a production-grade enterprise observability platform UI similar to Datadog, New Relic, Dynatrace, Grafana Cloud, and Elastic Observability.

Technology Stack:

* React 19
* TypeScript
* Vite
* Material UI (MUI)
* React Router
* TanStack Query
* Zustand
* Recharts
* React Flow (dependency maps)
* Monaco Editor (query editors)
* Axios

Theme:

* Modern enterprise SaaS
* Dark Mode + Light Mode --> can be switched!
* Responsive
* Professional dashboard design
* Support large datasets
* Virtualized tables
